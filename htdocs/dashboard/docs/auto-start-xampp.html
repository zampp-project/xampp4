Auto-Start ZAMPP

By default, you have to start ZAMPP or its components manually every time you reboot your system. However, you can also configure ZAMPP components to start automatically on system boot. Follow the steps below.

  1. Launch the ZAMPP control panel.

  2. Stop all the running ZAMPP components by clicking the "Stop" button next to each component.

  3. Click the "Service" button next to each component to install it as a service. Click "Yes" when prompted to confirm. This will install the corresponding service and set it to start automatically on boot.

  4. Reboot your system and the selected components should start automatically.

To revert the changes, simply uncheck the selected services in the ZAMPP control panel.
